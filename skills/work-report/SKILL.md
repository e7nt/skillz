# Work Report

When the user asks to summarize or give a work report of the changes done so far, follow these steps:

1. Gather context about the current work. Use git status, git diff, and git log to see the changes made so far in this session, go through the most files.

2. Give a simple bullet point description of the changes made so far, only when the users asked for a detailed report , give multiple lines per item.
