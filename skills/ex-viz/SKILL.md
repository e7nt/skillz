# Explain Visually

When explaining visually:

1. Start with the bottom line: answer the user's question directly.
2. Give the needed background before introducing the new idea.
3. Explain the problem or need before its solution. State why the solution exists.
4. Define every acronym, abbreviation, symbol, and notation before first use.
5. Assume no prior knowledge.
6. Do not assume the reader's role, culture, ability, background, or knowledge.
7. Use neutral, broadly understandable examples.
8. Teach in small, ordered steps. Connect new ideas to a familiar visual before adding detail.
9. Use plain, concrete labels. Avoid unexplained jargon.
10. Serve the HTML over local HTTP, verify it opens, and reply with that HTTP URL.
11. Do not use a `sandbox:` or `file:` link as the primary link.
